# Licensing

GroundSkills is a mixed-license repository.

## Default License

Files that do not carry a more specific license notice are licensed under Apache-2.0. See [`LICENSE`](LICENSE).

## Directory Exceptions

| Path | License | Notes |
|:---|:---|:---|
| `my_skills/blueprint-presentation/` | AGPL-3.0 | Includes an AGPL-3.0 license file and an upstream notice in `references/upstream.md`. |
| `my_skills/document-format-skills-main/` | MIT | Includes its own license file. |
| `my_skills/skill-creator/` | Apache-2.0 | Includes its own license file and matches the repository default. |

When a skill directory contains its own license file, that directory-level license takes precedence for files within that skill.
