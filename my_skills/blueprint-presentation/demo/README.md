# Blueprint Skill Manual Demo

这是一份用 Blueprint Presentation skill 制作的自说明 demo。它把“蓝图”本身作为主题：先在总览中展示结构，再通过节点进入组件、模式、保存机制和单文件交付等局部场景。

直接双击当前目录下的 `blueprint.html` 即可观看，不需要启动服务器。总览和局部场景都是可放大、缩小、自适应和平移的画布；局部场景还可以包含继续下钻的结构图组件。场景中的返回按钮会回到进入前的上一级。演示模式只允许浏览和跳转；切换到预演模式后，可以拖动组件、编辑部分文本，并通过保存按钮下载布局覆盖层。右上角的主题按钮可以轮换查看 Swiss 与 Editorial 两族九套受控预设，语言按钮用于切换界面操作文字。

新项目默认只需要编辑 `blueprint.source.json`：用节点、关系、场景和内容块声明核心内容，校验与打包脚本会自动生成底层配置。当前目录也保留了这份 demo 的制作文件，供后续迭代。`blueprint.html` 是打包后的单文件版本，已经内联样式、脚本、配置和图片，可以脱离源文件单独分发。
